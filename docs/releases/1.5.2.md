# Eclectic Light Updater 1.5.2 (build 12)

Each app name in the main list is now a button. Click the name, or the
information icon beside it, for a short description of what that app does and a
link to its page on the publisher's site. A product with no page of its own
links to a search of the site instead.

The app directory in Help carries fuller descriptions, two or three sentences
in place of a two-word label, and lists five more products: SilentKnight 3,
DeepTools, Quarant2, DeltaFree and AppexIndexer. The descriptions are editorial
summaries based on the publisher's Free Software Menu, reviewed 17 September
2026. The directory is bundled with the app and does not update by itself.

Nothing changes in how apps are found, compared or updated. Includes the
[symbolic-link fix from 1.5.1](1.5.1.md) and the
[Golden Gate compatibility update from 1.5](1.5.md).
Requires macOS 14 or later; supports Intel and Apple silicon Macs.

The command-line scripts in this repository changed separately: `organize` now
flattens apps into `/Applications/EclecticLight/` and collects PDF and RTF
documents into a `ReadMe` folder, as the README already described.
