# Eclectic Light Updater 1.5 (build 10)

The Mac app now recognizes macOS 27 Golden Gate when evaluating compatibility
descriptions and displaying the current OS name.

The [publisher’s September 12 compatibility article](https://eclecticlight.co/2026/09/12/which-of-my-apps-for-macos-golden-gate/)
supplements the live download catalog with 38 app releases and five command-line
tools. Evidence applies to the exact listed version and download URL. Newer
catalog releases keep their own descriptions; an unlisted app is not automatically
incompatible.

Publisher caveats remain visible: LogUI 1.1 refers to build 88; SilentKnight 3
requires Apple silicon; further work is planned for Cirrus and the virtualisation
apps, and T2M2 may need fixes. CLI tool compatibility reflects the publisher’s
belief rather than the app-testing statement.

Compatibility remains advisory and evaluates the catalog download, not an
installed app’s build. It does not enforce hardware requirements, guarantee
runtime behavior, or automatically choose an older compatible release.

Requires macOS 14 or later. The release supports Intel and Apple silicon Macs.
Open the release DMG and drag Eclectic Light Updater to Applications.

Automated coverage includes Golden Gate names and ranges, catalog identities,
version and archive isolation, preserved older OS descriptions, and repeated
catalog merging. Administrator installation and third-party app runtime behavior
are outside this compatibility update’s acceptance checks.
