# Eclectic Light Updater 1.5.1 (build 11)

Fixes app discovery following symbolic links and listing the same Applications
folder more than once. The scanner now inspects directory entries without
following symbolic links to folders or app bundles, and skips symbolic-link
scan roots. Directory-link cycles are skipped; real app copies in different
folders remain separate.

Includes the [Golden Gate compatibility update from 1.5](1.5.md).
Requires macOS 14 or later; supports Intel and Apple silicon Macs.

Regression tests cover folder links, app links, relative and broken links,
linked roots, cycles, and preservation of genuine separate copies.
