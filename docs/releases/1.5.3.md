# Eclectic Light Updater 1.5.3 (build 13)

Organize no longer asks for an administrator password when nothing needs one.

- **Every Organize ended with a password prompt.** After moving apps and
  collecting documents, an elevated pass to remove empty folders was queued
  every time, even when the app had already removed them itself. It is now
  queued only when there is a folder the app could not remove, or when elevated
  moves are already waiting and will empty folders later. On a Mac where you can
  write to `/Applications`, Organize now normally finishes with no prompt.
- **Folders created with administrator rights stayed owned by root**, so later
  runs then really did need rights to write into them. A folder the elevated
  step has to create is now handed back to you.
- **A move is only attempted without rights when it can finish.** Both folders
  must be writable, and across volumes the item must be your own. A move that
  stops part-way is reported and left in place; it is no longer retried with
  rights, which could have nested the item inside its own partial copy.
- The log says whether each move has happened or is waiting for the prompt.

Updating through Installomator, and installing a command-line tool's package,
still need an administrator password: both have to run as root. When several
operations need rights they still share one prompt.

Includes the [app descriptions from 1.5.2](1.5.2.md).
Requires macOS 14 or later; supports Intel and Apple silicon Macs.

Seven new tests cover moves in writable and read-only folders, handing folders
back, and when the elevated cleanup pass is and is not queued. The same change
was made to the command-line scripts in this repository.
